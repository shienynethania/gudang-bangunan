# Sistem Informasi Inventori Gudang Bahan Bangunan

Proyek Pemrograman Basis Data (Laravel + MySQL)

## Cara menjalankan
1. Nyalakan MySQL (Laragon: Start All)
2. Database `db_gudang_bangunan` dibuat di MySQL lokal lewat Workbench
3. `composer install`
4. Salin `.env.example` menjadi `.env`, atur `DB_DATABASE=db_gudang_bangunan`
5. `php artisan key:generate`
6. `php artisan serve`

## Fitur
CRUD master = role, user, satuan, vendor, margin penjualan, barang.
